## 为什么

当前库已经支持本地 `.txt`、`.md` 与 `.pdf` 导入，但很多个人知识库实际保存在笔记软件里，而不是裸文件目录。我们需要一条现实可用的有道笔记导入路径，但不依赖已受限的旧 OpenAPI。

## 变更内容

- 增加一个本地桥接式的有道笔记知识源，通过本机安装的 `youdaonote` CLI/Skills 命令导出数据。
- 先把笔记导出到临时本地目录，再复用现有本地导入管线。
- 当桥接命令不存在或导出失败时，返回清晰错误。
- 文档中明确说明这是本地桥接，不是直接的 OpenAPI 接入。

## 能力

### 新能力

- `youdao-note-bridge-import`：通过本地有道笔记 CLI 导出桥接导入个人知识。

### 修改的能力

- 无。

## 影响范围

- 增加一个新的根包知识源类型与本地桥接执行逻辑。
- 增加桥接命令探测和临时目录导入测试。
- 更新 README，说明桥接方式和前置条件。
